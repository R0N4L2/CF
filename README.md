# Optimización logística para Corporación Favorita (proyecto SmartBP)

**En una frase:** soluciones de optimización para armar pallets, hacer picking y llenar furgones en la cadena de distribución de Corporación Favorita (Ecuador).

## Contexto
Proyecto de consultoría de optimización logística. El repositorio reúne el código, los modelos y los entregables de la **Fase 1** (presentaciones "Cierre Fase 1" e "Integración FAVORITA SmartBP", y comparativos en Excel entre la solución y la operación actual).

## Componentes (según las carpetas del proyecto)
| Carpeta | Propósito |
|---|---|
| `CreacionPallets` / `CreatePallets` | Armado de pallets |
| `Consolidacion` | Consolidación de pedidos |
| `asignarFurgones` | Asignación de carga a furgones |
| `jabas`, `bins` | Manejo de jabas (cajas) y contenedores |
| `Legos`, `MasterRun` | Módulos reutilizables y ejecución maestra del flujo |
| `Favorita_Mundos` | Escenarios/instancias del problema |
| `Graficar.py` | Visualización de resultados |
| `codigodespacho_*_nave_*.html` | Visualizaciones interactivas de la carga por nave/despacho |

## Tecnologías
Python · optimización matemática · visualización HTML
